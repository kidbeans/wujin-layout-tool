## 一、怎么放到手机

1. 把 `无尽布阵工具_手机版.html` 传到手机：微信「文件传输助手」/ QQ / 数据线 / 网盘都行。
2. **用手机浏览器打开**（Chrome / Edge / 三星浏览器 / 夸克 / iOS Safari 都可以）：
   - 微信里点开常被内置浏览器限制 → 右上角「⋯」→「用其他应用打开 / 在浏览器打开」；
   - iPhone：先把文件存进「文件」App，点开预览即可用；若发现交互受限，在分享里选「用 Chrome/Edge 打开」。
3. 建议「**添加到主屏幕**」：已内置 `theme-color` 与 `apple-mobile-web-app-capable`，
   加完像个小 App，图标点开即用，也没有地址栏占地方。
4. 阵型数据存在**手机浏览器本地**（localStorage），关掉再开还在；换手机/换浏览器请用下面的「带走阵型」。
   ⚠ iPhone 上本地存储配额较小（约 5MB）：别在「换肤」里选大图当壁纸（会占存储），阵型文本本身很小、不受影响。

## 二、手机上的界面：棋盘当主角，其它都是悬浮窗

按你的要求：**棋盘铺满、其余收小做成浮层**。

```
┌────────────────────────────┐
│ 顶栏（标题 + 主题）              │
│ ┌─ 左图标栏 ─┐  🌱 布阵草坪棋盘   │  ← 棋盘 = 主舞台，9 列一屏装下
│ │ 阵型 顺序 …│  ┌─────────────┐ │
│ │ 路由 Boss │  │ 1 2 3 … 9   │ │
│ │ 检查 存档 │  │ 路1 ▢▢▢▢▢▢▢▢▢│ │
│ │ 导入导出  │  │ …            │ │
│ └──────────┘  └─────────────┘ │
│  🪴植物库 🎴卡槽 ⚙️工具 📤导出 🔍放大 │  ← 底部 FAB，点开即浮层
└────────────────────────────┘
```

- **底部 5 个键**（点开/再点收起，点抽屉外空白处也收起）：
  - 🪴 植物库：选植物/融合/藤蔓/工具**画笔**（选中植物后抽屉自动收起，接着点格子落种）
  - 🎴 卡槽：配队1（卡槽1~8）/ 配队2（9~16）
  - ⚙️ 工具：导出文本、复制全部、导入阵型、清空棋盘/卡槽、特效、分阵型、**棋盘尺寸（列数/行数）**
  - 📤 导出：导出结果文本框（可直接编辑后复制 / 导出 txt）
  - 🔍 放大：格子变 46px，棋盘可左右上下拖；再点「收起」回到一屏装下
- **左栏图标**（顺序 / 路由 / Boss / 检查 / 存档 / 导入导出 / 服务 / 帮助 / 换肤 / 设置）沿用工具自带
  的「工具坞」，手机端它从右侧 480px 栏变成**底部浮层**（右上角 ✕ 收起，或点浮层外任意空白处、
  或点底部任意 FAB 键都会收起），不占棋盘位置。
- **手势**：
  - 点植物 → 点格子 = 放置；连点多个格子 = 连续粘同样组合
  - **长按格子 = 清空该格**（等同桌面右键；已做长按后吞掉抬手补发的那次 click，不会刚清完又种回去）
  - **双击格子 = 手输入植物名**（输入 `-` 清空）
  - 双指缩放仍可用（想看清格子细节时直接捏合放大）
- 首次打开会弹一条操作提示，点掉即可（只提示一次）。

## 四、手机能做什么 / 不能做什么

| 功能 | 手机版 |
| --- | --- |
| 棋盘 / 卡槽 / 顺序 / 路由 / Boss 全套编辑 | ✓ |
| O1~O10 体检、金卡推演、链检查器 | ✓ |
| 导出 JSON v2 / 复制全部 / 导出 txt / 导入（粘贴或选文件） | ✓ |
| 存档导出导入（换手机带走阵型） | ✓ |
| Agent 工作台（AI 对话、任务包） | — 需要电脑上的本地后端，手机版会提示/空转 |
| 🚀 一键部署到 MPZ、MPV 原生直读 | — 需要桌面版 exe |
| 完成通知 | — |
| 控制台报 404（`/api/ping`、`agent_model/*`） | 正常现象：浏览器/手机版本来就没这些接口，不影响布阵与导出 |

**在手机和电脑之间搬阵型**：手机上调好 → 「📤 导出 → 导出 JSON v2」（得到 .json 文件）或「⚙️ 工具 →
复制全部」（得到文本）→ 传到电脑 → 桌面版「导入阵型 / 应用粘贴的 JSON v2」。反向同理。

## 五、重新打包（v4 源改动后）

```bash

```

- 打包器只做加法：**原 v4 的 CSS/JS 一个字都不改**（脚本会反向剥离注入层并与源文件逐字节比对，
  不一致就拒绝产出）；重复运行会先剥掉旧注入层再注入（可升级），并在覆盖前备份旧产物。

### 修过的两个手机端真问题（2026-10-08 用户反馈）

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 点左栏功能（顺序/路由…）后**关不掉**，只能刷新页面 | ① v4 自带 `#v3dock{position:absolute; top:0; bottom:0}`，手机端只覆盖了 `bottom` → 坞贴在屏幕顶部；② 坞头 ✕ 只有 26px，且被吸顶栏 `#v3tb`（`z-index:1400`）**盖住命中点**（`elementFromPoint` 落在顶栏主题键上） | 手机端 `#v3dock{ top:auto !important; position:fixed }` 改贴底；坞头 44px、✕ 加大到 36×36；`z-index` 分层（顶栏 1400 / FAB 1300 / 抽屉 1160 / 坞 1150 / 遮罩 1140） |
| 点别处无法让它消失 | 遮罩只在自建抽屉打开时出现，工具坞不在覆盖范围 | `body.v3dockopen #mpzOverlay{display:block}`；遮罩点击统一走 `closeAllPanels()`（先走 v4 自己的 ✕→`v2ClosePanels` 路径，60ms 后兜底撤 `v3dockopen` 类） |
