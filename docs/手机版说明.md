## 1 怎么放到手机

1. 把 `无尽布阵工具_手机版.html` 传过去，微信「文件传输助手」、QQ、数据线、网盘都行。
2. 用手机浏览器打开：Chrome、Edge、三星浏览器、夸克、iOS Safari 都可以。微信里点开常被内置浏览器限制，
   右上角「⋯」选「用其他应用打开 / 在浏览器打开」；iPhone 先把文件存进「文件」App，点开预览就能用，
   交互不顺就在分享里选「用 Chrome/Edge 打开」。
3. 建议再「添加到主屏幕」。文件里已经内置 `theme-color` 和 `apple-mobile-web-app-capable`，
   加完图标点开像个小 App，也没有地址栏占地方。
4. 阵型数据存在手机浏览器本地（localStorage），关掉再开还在。换手机或者换浏览器，用下面说的带走阵型。
   iPhone 的本地存储配额比较小（约 5MB），别在「换肤」里选大图当壁纸，阵型文本本身很小，不受影响。

## 2 手机上的界面

布局就一个原则：棋盘当主角，其它收成浮窗。

```
┌────────────────────────────┐
│ 顶栏（标题 + 主题）              │
│ ┌─ 左图标栏 ─┐   布阵草坪棋盘      │   ← 棋盘 9 列一屏装下
│ │ 队型 顺序 …│  ┌─────────────┐ │
│ │ 路由 Boss │  │ 1 2 3 … 9   │ │
│ │ 检查 存档 │  │ 路1 ▢▢▢▢▢▢▢▢▢│ │
│ │ 导入导出  │  │ …            │ │
│ └──────────┘  └─────────────┘ │
│  植物库 卡槽 工具 导出 放大        │   ← 底部五个键，点开即浮层
└────────────────────────────┘
```

底部五个键，点开是浮层，再点一下、点浮层外空白处都会收起：

- 植物库：选植物、融合、藤蔓、工具画笔。选中植物后抽屉自动收起，接着点格子就落种。
- 卡槽：配队1（1~8）和配队2（9~16）。
- 工具：导出文本、复制全部、导入阵型、清空棋盘/卡槽、特效、分阵型，还有棋盘尺寸（列数/行数）。
- 导出：导出结果文本框，可以直接编辑再复制或者导出 txt。
- 放大：格子变 46px，棋盘可以上下左右拖；再点一下回到一屏装下。

左边那一列图标（顺序、路由、Boss、检查、存档、导入导出、服务、帮助、换肤、设置）用的是工具自带的工具坞，
手机端它从右侧 480px 栏变成底部浮层，不占棋盘位置。收起方式有三种：坞头右上角的叉、点浮层外任意空白、
点底部任意一个键。

手势：

- 点植物，再点格子是放置；连着点多个格子是连续粘同样的组合。
- 长按格子等于桌面的右键，清空该格。长按触发后会吞掉抬手时浏览器补发的那次 click，不会刚清完又种回去。
- 双击格子是手输入植物名，填 `-` 清空。
- 双指缩放照常可用，想看清格子细节就捏合放大。

第一次打开会弹一条操作提示，点掉就行，只提示一次。

| 姿势 | 格子 | 棋盘 |

## 4 能做什么与不能做什么

| 功能 | 手机版 |
| --- | --- |
| 棋盘 / 卡槽 / 顺序 / 路由 / Boss 全套编辑 | 有 |
| O1~O10 体检、金卡推演、链检查器 | 有 |
| 导出 JSON v2 / 复制全部 / 导出 txt / 导入（粘贴或选文件） | 有 |
| 存档导出导入（换手机带走阵型） | 有 |
| Agent 工作台（AI 对话、任务包） | 没有，要电脑上的本地后端 |
| 一键部署到 MPZ、MPZ 原生直读 | 没有，需要桌面版 exe |
| 完成通知 | 没有 |
| 控制台报 404（`/api/ping`、`agent_model/*`） | 正常，那些接口只有桌面版才有，不影响布阵和导出 |

手机和电脑之间搬阵型：手机上调好，「导出 → 导出 JSON v2」得到 json 文件，或者「工具 → 复制全部」得到文本，
传到电脑，桌面版「📥 导入」面板选文件或粘贴后点「解析 → 应用到画布」。反方向同理。

## 5 重新打包与改源码

```bash
python "E:\app\backup_mpz_scripts\布阵工具\v4\tools\build_mobile_html.py"        # 生成/刷新手机版
python "E:\app\backup_mpz_scripts\布阵工具\v4\tools\build_mobile_html.py" --check # 只体检不写文件
```

打包器只做加法，原 v4 的 CSS 和 JS 一个字都不改：脚本会反向剥掉注入层，跟源文件逐字节比对，
不一致就拒绝产出。重复运行会先剥掉旧的注入层再重新注入，也能升级适配层，覆盖前还会备份旧产物。
要改手机端的行为或样式，改 `v4/mobile/mobile_layer.css`、`mobile_layer.js` 再重跑打包器。

修过的两个手机端真问题（2026-10-08）：

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 点左栏功能（顺序、路由…）后关不掉，只能刷新页面 | v4 自带 `#v3dock{position:absolute; top:0; bottom:0}`，手机端只覆盖了 `bottom`，坞贴在屏幕顶部；坞头的叉只有 26px，还被吸顶栏 `#v3tb`（z-index 1400）盖住命中点，`elementFromPoint` 落在了顶栏主题键上 | 手机端改 `top:auto !important; position:fixed` 贴底；坞头 44px、叉加大到 36×36；z-index 分层：顶栏 1400 / FAB 1300 / 抽屉 1160 / 坞 1150 / 遮罩 1140 |
| 点别处无法让它消失 | 遮罩只在自建抽屉打开时出现，工具坞不在覆盖范围 | `body.v3dockopen #mpzOverlay{display:block}`；遮罩点击统一走 `closeAllPanels()`，先走 v4 自己的叉（`v2ClosePanels`）路径，80ms 后兜底撤掉 `v3dockopen` 类 |
