## 1. Bug 清单与修复方案

### P0（导出正确性）

**P0-1 尾数输入框清空 → 尾数 0（15_route.js:191-193）**
- 现象：`rc.tail.d2 = (q('rtD2Tails')||'').split(/[,\s，]+/).map(Number).filter(x>=0&&x<=9)`。
  输入框清空时 `''.split(...)` = `['']`，`Number('')===0`，且 0 过范围过滤 → **空输入被解析成尾数 0**。
- 影响：Boss 尾数框清空 → `[0]` → 第 10/20/30… 关全被判为 Boss 关；deck2 尾数框同理误变 `[0]`。
- 修：过滤前剔除空串（`filter(x !== '')`），`rtDeck2Lv` 同模式对齐（其 `x > 0` 过滤已天然剔除 0，但空串→NaN 后同样被滤，需一并校验行为）。

**P0-2 融合材料卡槽缺失 → 坏锚点「第undefined个槽位」（20_order.js:308）**
- 现象：`pushPlant(x, x.merge, v2FindSlot(x.merge) || (s1 && s1 <= 8 ? null : null), { pre: 200 })`——
  三目表达式两个分支都是 null，恒 null。材料卡（原豌/电豌等）不在任何卡槽时，slot=null。
- 影响：导出时 `v2SlotAnchor(null)` → `'种植物_初始化_第undefined个槽位'`，管线运行到该节点 bad next。
- 修：材料卡槽缺失时跳过该材料步；`v2OrderIssues` 增加「plant 步缺 slot」error 提示。

**P0-3 主题弹窗圆点 t.dot 未定义（97_theme.js:319）**
- 现象：`'<span class="tp-dot" style="background:' + t.dot + '">'`，但 V2_THEMES 表中无 dot 字段 → `background:undefined`。
- 修复：给 11 套主题补 dot 色值（取各自强调色）。

### P1（交互正确性）

**P1-4 Ctrl+Z/Ctrl+Y 全局拦截无输入框守卫（90_boot.js:148-153）**
- 现象：keydown 直接 `v2Undo()`，在存档名/前缀/格子坐标等输入框中按 Ctrl+Z，原生文本撤销被吞、整个棋盘回滚。
- 修：target 为 input/textarea/contentEditable 时放行。

**P1-5 fallbackCopy 顺序颠倒（00_v1_app.js:838-846）**
- 现象：先 `document.execCommand('copy')`（此时未选中任何内容，必败）再创建 textarea+select。
- 修：先建 textarea → select → execCommand → 按结果提示。

**P1-6 v2ImportJSON/v2RestoreAll 存档尺寸不匹配无防护（10_state_v2.js:29-66）**
- 现象：`grid = d.boards.main` 直接赋值；旧存档 rows/cols 与当前不一致时 renderGrid 越界读 undefined。
- 修：恢复前按 cols×rows 裁剪/补齐。

**P1-7 v3setTheme 只认 dark/light（97_theme.js:283）**
- 现象：`self.apply(ns.value === 'dark' ? 'dark' : 'light')` 会把扩展选项折算掉。
- 核对：`v3_chrome.html` 中 `#v3setTheme` 选项仅 dark/light → 行为本正确；保持现值直传（防御性），不改选项集。
