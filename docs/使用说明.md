# 使用说明

桌面版和网页/手机版是同一套界面，功能也一样，桌面版多几个跟本机有关的能力（见[两个版本的差别](#两个版本的差别)）。
工具里按 F1 打开的是同一套帮助的精简版。

数据都存在本机：桌面版在应用数据目录，网页版在浏览器 localStorage。换设备靠「导出 JSON v2」或者存档导出带走。

## 先打开

桌面版下载便携版 exe 双击就跑；想要开始菜单和桌面快捷方式就用安装器。要 Windows 10/11 x64，依赖系统自带的
WebView2。

网页/手机版开 <https://kidbeans.github.io/wujin-layout-tool/> 就行，也可以把 `index.html` 存到本地离线用。
手机浏览器里建议「添加到主屏幕」，点开跟小 App 一样。

## 三分钟先出一套阵

1. 左栏「预设」里挑个世界预设一键载入。里面有十五套验证过的脚本画像（复兴、桑葚、童话、埃及、西部、海盗、
   龙芋、功夫、功夫纯火龙 v2、未来、黑暗、黑暗纯火龙 v2、沙滩火龙、沙滩桑葚、冰河），阵型、卡槽、顺序、
   路由、Boss、抛花都齐了，载入微调就能导。
2. 植物库里点植物，再点棋盘格子放下；也可以直接拖。把植物拖进卡槽就是配队。
3. 顶部「顺序」打开顺序面板，点「生成草案」一键出种植链。瓷砖格会自动排到链尾铺瓷砖萝卜；金卡主力超过 3 格时，
   前 3 格优先排在还没被主力覆盖的行上，O9 更容易过。
4. 点「检查」看 O1~O9 体检，error 清零再往下走（O9 那条「超初始 3 次」是 info，不拦）。
5. 左栏「导入导出」里「生成 pipeline 片段」拿脚本，或者直接「部署到 MPZ」。

## 界面在哪

左边一列图标：阵型、Agent、预设、顺序、路由、Boss、检查、存档、导入导出、服务、帮助、换肤、设置。
顶部一排按钮管全局：导出文本、复制全部、导入阵型、清空棋盘、清空卡槽、恢复默认植物库、清空种植卡、
特效、分阵型。

中间是三块：植物库、棋盘、配队卡槽。棋盘那块的右下角有「列数/行数 + 应用尺寸」。
手机上这三块会收进底部浮窗，见[手机上怎么用](#手机上怎么用)。

## 棋盘

- 放置和擦除：点选画笔后点格子就放上去。右键清空格子或者卡槽；在植物库右键某个植物名，是把它从库里删掉。
- 互换：格子跟格子对着拖就是互换；拖列头整列互换，拖行号整行互换。
- 复制画笔：把画笔清空（点棋盘空白处取消选择）后点某格，那格的组合就进画笔了，再点别的格子连续粘。
- 改名：双击格子手改主植物名，填 `-` 是清空。
- 瓷砖：工具组里的「放置/移除瓷砖」。它独立于植物，也不参与复制，导入文本里写成 `[瓷]`。
- 动作：分棋盘专用的抛花、抛蕾、喂豆、铲除、delay。点格子会把动作追加在那格组合后面，能叠着加，
  比如「大守卫菇 + 喂豆 + delay500 + 铲除」。
- 抛花：路由面板勾上「小关抛花」，再填花用的卡槽和落格（像 7-1,7-2）。导出时 deck1 的「点波_初始」后面
  会自动插一步抛花，task 里也带「小关是否抛花」开关和每朵花的行列坐标，之后在 MPZ 界面照样能改格号。
- 特效开关：关掉后棋盘只留瓷砖和芦荟的提示。「分阵型」打开会变成总阵型/前期/后期三张棋盘，
  可以点「校验一致性」逐格比对前期加后期是不是等于总阵型。

## 叠种与融合

藤蔓（毒藤、南瓜头、豆藤、小守卫菇）叠在主植物上，棋盘上显示成 `桑葚(毒藤)` 这样，一格最多一种藤蔓。
融合（原豌、电豌、火豌、冰豌、毒豌）只能叠在「大哥」上，显示成原大、电大、火大、冰大、毒大，
导出时仍然写成完整的大哥加材料两步。

导入文本时组合写法都认：`原大=大哥+原豌`，`原碗` 会自动纠成 `原豌`，`-` 或留空等于空格。

## 卡槽与配队

卡槽 1~8 是配队1，点「配队2」展开 9~16（面板里带植物头像）。
归属要盯紧：deck1 的种植步只能用 1~8，deck2 的步只能用 9~16。写混了进关会摸到另一套配队的卡，
静默种错植物，O10 会拦下来。

## 顺序链

- 生成草案：按棋盘加卡槽一键出链。融合的两步会排成相邻，按槽分组，需要的地方自动插结算检查。
- 画笔追加：顺序面板开着的时候，用植物画笔点格子就是往链里追加一步，同一格会去重。
- 手动加步：加步栏的「+种植」能临时插任意卡槽、任意格子的步，调试用，不必先在棋盘上摆出来。
  所有加步都自动插到链尾点波之前；加在点波后面就是孤儿步，永远不会执行。位置靠拖拽或上下箭头调，
  行内能直接改格子、卡槽、pre/post。
- 「检」：给那一步挂 ColorMatch 金卡检测，卡用完了就走回退。一般从第 2 个融合格开始挂。
- 校验规则一共十条：O1 覆盖、O2 融合次序、O3 时序、O4 检测位、O5 插缝、O6 deck2 专属点波、O7 捡花、
  O8 节奏、O9 金卡次数加行覆盖、O10 卡槽归属。
- 金卡推演（O9）：无尽开局每种金卡只有 3 次，推演就按前 3 次算。它检查第一关开始时每一行是不是至少
  有一个守阵主力——大哥（含各种 x 大）、洋芋、桑葚、药师、暗物质火龙果算主力，气流和珊瑚这类辅助不算，
  军炮那一类迫击炮所在的行直接算安全。判读时分清两件事：「超初始 3 次」是 info 不是错误，那是留给后面关卡
  和铲补的通用位，第一关不生效是预期；真正要修的只有「融合格超次的大哥没挂检测」和「某行没有守阵主力」。
- 链路可视化：顺序面板开着时棋盘上叠步数徽章，金色是金卡步，绿色是追踪安全，红色是超 3 次失效；
  行号绿勾表示这行有主力，黄叹号只有追踪，红叉没主力。鼠标停在哪一步，棋盘对应格高亮。嫌乱可以关掉。

## 配队路由

三种模式对着自己的脚本选：尾数分流（复兴、童话、龙芋这些）、阶段分流（海盗）、无计数（埃及、西部这类单卡组）。
参数旁边一般带「已验证预设」，一键填好；「规则自检」会跑一组测试向量。

平时常动的就四个：deck2 走哪几个尾数、Boss 是哪几个尾数、前 N 关先不切 deck2（开荒期让 deck1 先成型）、
前 10 或前 30 关是速刷还是等结算。

两个单独的开关：

- N 关起补白萝卜（bailuo_from）：从第 N 关起普关进「重种白萝卜」的循环，防禅杖僵尸把阵型整体吸歪
  （火龙 v2 用 60）。落格和槽位会自动取 deck1 顺序里的白萝卜步，留空就是关掉。
- 关内点波（wave_mode）：填了以后导出的 task 才会带「关内点波」三档——不点波只等结算最稳、默认点波5/点波1
  交替、狂点是突发连点，你填的那档就是默认；留空不生成这个选项，保持旧行为。

「模拟」会按关卡序列逐关判定分流，能看计数条和单关的判定链。

## Boss 关链

两套范式挑一套：叠电大是叠两轮、能量花、加速、循环喂豆（复兴、西部）；喂豆开大是喂豆、加速、喂豆、循环
（童话，末步记得勾「循环」）。

「识别boss关 → 神器补给」这段骨架导出时会自动补齐。面板里可以生成「喂豆位置」下拉（45 格可选），
B1~B7 是一键校验，其中 B7 专门拦「Boss 关用 deck2 卡槽」的叠种。

## 检查与日志

检查面板一次能喂好几样：pipeline JSON（可多选，会合并成一张图）、task/interface、agent 与 maafw 日志。
静态规则是 S1~S22、T1~T7、V1~V2，管断链、悬空节点、max_hit 误用、坐标越界、卡槽 9~16 别名、点波四元组、
Boss 色值、OCR 完整性这些。选两份 pipeline 会出节点级 diff；喂 agent 日志会生成时间线，
把喂豆、铲除、检测事件对齐着看。

## 导入导出

先把三种文件分清，混了必失败：

- v2 阵型 JSON（源底稿）：纯 JSON，开头是 `{"version":2,"meta":…`，装着棋盘、卡槽、顺序、路由、Boss。
  改阵型全靠它回灌，入口是「应用粘贴的 JSON v2」。
- 存档槽位整包：若干具名槽位打成一包，换机或多套阵型带走用，入口是「存档」面板的「粘贴 → 导入全部」。
- pipeline 片段：一整块大文本，结构是体检注释、pipeline 节点 JSON、task 片段三段拼在一起，
  这是给 MPZ 的成品形态。它不能整份导入，部署时按下面的步骤拆开。

最常犯的错就是把 pipeline 片段粘进「应用粘贴的 JSON v2」，或者把存档整包当成 v2 JSON 导入。
先看文件开头长什么样，再选入口。

四种导入途径：

- 手里是 v2 阵型 JSON：导入导出面板的大文本框整段粘贴，点「应用粘贴的 JSON v2」，棋盘、卡槽、顺序、
  路由、Boss 全部还原，可以撤销。
- 手里是存档整包：存档面板里粘进 IO 框，点「导入全部」，列表里出现各个槽位，点要用的载入。
- 手里是已经部署的 MPZ pipeline（`YS_*.json`、`Endless_*.json` 这类纯 JSON，可多选合并）：
  导入导出面板下半区选文件，点「解析（先看报告）」，它按链规则还原出步数、植物名、路由和警告；
  读过报告没问题再点「应用到画布」。
- 桌面版还有一条路：Agent 工作台里点「应用到布阵」，会从 AI 的回复里自动提取 v2 JSON 或片段应用上去。

从画布到能跑的脚本，七步：

1. 把五件套配齐——棋盘、卡槽（用配队2 就展开）、顺序链（deck1 和 deck2 都要）、路由、Boss 链，
   然后跑「检查」和「金卡推演」，O 和 B 全部 0 error（O9 的「超次」info 不算）。
2. 存源底稿：点「导出 JSON v2」下载一份 json。这步别省，以后改阵型、换电脑、让 AI 改，都靠它回灌。
3. 定前缀和任务名：面板顶部「节点前缀」填这套脚本独用的前缀（fx_、ty_ 这种，不能跟 MPZ 里已有的重名）；
   「任务名」可以自定义，会写进 interface.json，留空会自动生成并记住。
4. 点「生成 pipeline 片段」拿三段式文本。分界标记就写在文本里：先是头注释（体检结论，error 必须清零），
   然后是「↓↓② pipeline 节点 JSON」，再是「↓↓③ task 片段」。用「复制」或「下载 .json」取走都行，
   不拆也没关系，下一步可以一键部署。
5. 一键部署（推荐）：点「部署到 MPZ」，工具会把该做的都做了——先过体检 error 门，没清零会拦下并列清单；
   然后写 `resource_self/pipeline/Endless/YS_前缀.json` 和 `resource_self/task/前缀_wj.json`；
   再在 interface.json 里注册（resource 加「自制无尽」、import 加片段、task 加条目，幂等不重复）；
   最后检查 agent 计数器，main.py 自动补 import，fx_counter.py 缺了就用内置源码写进去。
   会被覆盖的文件都先备份成 `*.bak.时间戳`，过程显示在导出框里。前提是桌面版加上「服务」面板里
   MPZ 根目录填对，根不对时一个文件都不会写。
6. 重启 MPZ（MFAAvalonia）重载资源，任务列表的资源切到「自制无尽」才能看到自制任务。
7. 第一次跑：勾上「初始化卡槽和草坪位置」（首次运行或换分辨率必开），「启动时关卡数」填当前关
   （中途加入一定要填），想看实时关卡数就把「监控窗口」开着。

几个部署相关的细节：

- 一键部署是幂等的，同一张画布反复点不会重复注册。官方 interface.json 哪天被大更新覆盖了，
  挨个打开阵型画布点一次「部署到 MPZ」就能全部还原，agent 的计数器 import 也会自动补回来。
- 手动拆装（学原理或离线机器）：第二段存成 `resource_self/pipeline/Endless/YS_名字.json`，
  第三段的 option 合并进 `resource_self/task/前缀_wj.json`；interface.json 动三处——resource[] 加
  「自制无尽」这条（path 是 `./resource` 和 `./resource_self`），import[] 加片段路径，task[] 加条目
  （name、entry、option、resource）。改完必须还是严格 JSON，不能有注释和尾逗号。
- 任务简介不用手写：第三段 task 里的 description 已经按现网「卡槽 配队1[…]｜注意…」的格式生成好，
  注册 task 时原样抄进 description 就行。
- 部署完怎么验：检查面板里选刚部署的文件，S1 断链应该是 0；任务列表资源切「自制无尽」能看到任务。
- 回滚：被覆盖的文件旁边都有 `*.bak.时间戳` 副本，改回文件名就回去了。

## 容易踩的坑

工具自己能拦一部分（O、B、S、T 系列）。下面这些它拦不了，自己留神：

- 三种文件格式别混，按文件开头特征选入口，上面那章讲过。
- 同一个 MPZ 里每套脚本的前缀必须独立，撞名会互相覆盖。
- deck1 用了 9~16、deck2 用了 1~8 是静默种错的坑，O10 会拦。
- 「检」的检测条坐标是按官方槽位探针推算的，卡槽 3 是实测校准值，别的槽位第一次上机最好自己实测一次，
  O10b 会提示。
- 节点名就是 agent 的契约：改写路由靠节点名，`计步` 参数里必须显式写 `route_node`（比如 `fx_尾数路由`）。
  不写的话前缀会回落成 `fx_`，这套脚本的尾数分流和喂豆改写就全落空。
- 一个 custom 节点只能被一个 input 覆盖，两个 input 同时改会互相污染（T2 会拦）。
- 经 MPZ 界面覆盖过的 `custom_action_param` 变成双层编码，外层是个字符串，agent 端要解两层。
  现成的计数器代码已经处理了，自己写 agent 时注意。
- pipeline 里等识别结果的时间预算算在父节点上。父节点没写 `timeout: -1` 又等的是长事件（比如 Boss 战结算），
  20 秒就会超时炸断链。给那个正在等的节点加 `timeout: -1`。
- 融合格的金卡检测不是每格都挂，一般从第 2 个融合格起，位置跟着种植顺序走；顺序改了检测位置也要跟着挪，
  O4 会提示。
- 坐标按 720 短边录的，换分辨率要重开一次「初始化卡槽和草坪位置」。
- 引用 `种植物_初始化_*` 那些锚点之前，脚本必须先走过一次初始化链，否则报 `get_rect_from_node node not found`。
- agent 计数器是所有自制无尽共用的，两个自制任务不要同时跑。

## 存档、主题、快捷键

整包存档（棋盘加卡槽加顺序加路由加 Boss）存在浏览器 localStorage 里，换机用「导出全部(JSON)」带走，
桌面版状态栏会显示自动存档时间。撤销重做是 Ctrl+Z / Ctrl+Y，深度 100。

快捷键不多：F1 开关帮助手册，Esc 关面板（桌面版还会收起右坞），桌面版 Ctrl+K 打开 Agent 工作台，
Ctrl+1/2/3 切视图。主题在顶栏月亮图标里切深浅色，「换肤」里还有别的配色和壁纸。

## 两个版本的差别

| | 桌面版 | 网页/手机版 |
| --- | --- | --- |
| 棋盘、卡槽、顺序、路由、Boss、检查、导出 | 有 | 有 |
| Agent 工作台（AI 对话、任务包） | 有 | 没有 |
| 一键部署到 MPZ、原生「另存为」、完成通知 | 有 | 没有 |
| 保存文件 | 原生另存为 | 浏览器下载 |

手机/网页版控制台偶尔报 `/api/...` 404 是正常的，那几个接口只有桌面版才有。

## 手机上怎么用

界面跟桌面版同源，窄屏时自动变成棋盘占满、其余收进底部浮窗。

- 底部五个键：植物库、卡槽、工具、导出、放大。点开是浮层，点浮层外面或者再点一下按钮就收起。
- 点植物，再点格子就放上去；连着点几个格子等于连续粘同一个组合。
- 长按格子是清空，双击格子是手改植物名（填 `-` 清空）。
- 左边那一列图标（顺序、路由、Boss、检查、存档、导入导出、帮助、设置）也是底部浮层，
  右上角的叉收起来。

阵型存在浏览器本地，关掉再开还在。手机和电脑之间搬阵型：手机上「导出 → 导出 JSON v2」存文件，
或者「工具 → 复制全部」拿文本，电脑上桌面版「导入阵型 / 应用粘贴的 JSON v2」接着弄；反方向一样。
第一次打开会弹一条操作提示，点掉就行，只提示一次。

## 常见问题

- 金卡 3 次是什么意思？无尽开局金卡（橙色植物）每种只有 3 次种植机会，超出就种不下，
  O9 就是按这个判断开局阵型能不能立住。
- 为什么「原大」显示橙色而「原豌」是蓝色？叠在大哥上的融合体是金卡本体，材料品质只影响材料自己的种植次数。
- 数据存哪？浏览器 localStorage。重要阵型用存档导出，或者导出 JSON v2 带走。
- 导出后点「下载 .json」弹的是打开而不是另存为？2026-09-06 已经修成另存为，老版本更新一下桌面壳。
- 部署完在 MPZ 里找不到任务？任务列表的资源要切到「自制无尽」。
- 手机上为什么没有「一键部署到 MPZ」？那个要读写本机文件、还要跑 agent，只有桌面版能做。
  手机版调完阵型导出带走就行。
