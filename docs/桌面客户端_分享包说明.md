## 二、系统要求

- **桌面版 exe**：Windows 10/11 x64。依赖系统自带的 WebView2 运行时（一般已预装）；若打开报缺 WebView2，运行 setup 安装器即可。**不需要 Python、不需要 Node。**
- **单文件 HTML**：任意现代浏览器（Chrome / Edge / Firefox），双击打开即用，同样**不需要任何环境**。

## 三、隐私：API key 会随包传播吗？

**不会。** 你在设置里填的 API key（以及阵型、存档、Agent 对话）只存在**本机**应用的 WebView localStorage
（`%APPDATA%\com.mpz.wujinbz.v3beta\` 数据目录），不写进程序文件、不写进本包任何文件。
本包的 exe / html / source 出厂时**不含任何 key**；「复制任务包」「任务包.md」也只含技能与上下文，不含 key。
把 key 带到别的电脑只能手动重填一次（或自行备份上述数据目录）。

2. 按 <kbd>F1</kbd> 打开内置帮助手册——**「📥📤 导入导出全流程」一章可照抄步骤**：从画布到能跑的 MPZ 脚本七步、一键部署、常见坑都在里面。
3. 数据自动存本机；换机请用「💾 存档」面板「导出全部(JSON)」或「导出 JSON v2」带走。

## 六、部署到 MPZ（跑自动化脚本）

需要：本机装有 MaaPVZ（`E:\app\MaaPVZ-win-x86_64` 或其他位置）。

1. 桌面版左栏「🌐 服务」面板设置 MPZ 根目录（可「📁 浏览…」选择）。
2. 画布配好后，导入导出面板点 **「🚀 部署到 MPZ」**——pipeline/task/interface 注册/agent 计数器一次做齐
   （fx_counter.py / fx_monitor.py 缺失时用内置源码自愈写入），改前自动备份 `*.bak.时间戳`。
3. 重启 MPZ（MFAAvalonia），任务列表资源切「自制无尽」即可看到你的任务。
4. 详细说明、坑位、回滚方法：F1 帮助 5.3/5.4 节。

## 七、source/ —— 源码与重新打包

```
source/
├── core/            v2 逻辑基座（src/ 单一事实源：棋盘/顺序/导出/部署/帮助等）
└── app/             v4 应用工程（Tauri 2 壳 + v3 前端 + tools/test/webui.py）
```

- 重新打包桌面版（需 Rust(msvc) + Node 18+）：

  ```
  cd source/app
  python tools/build_app.py          # 全流程：拼 ui → 刷新包根网页 → cargo → NSIS → dist_shell → 三交付物（网页/exe/安装包）归位到 v4 根（旧件自动 *.bak.时间戳）
  python tools/build_app.py --fast   # 只改了前端：重拼 ui 并刷新包根网页（exe 需去掉 --fast 完整构建才更新内嵌前端）
  ```

  build.py 自动从 `../core/src` 取逻辑基座（也兼容开发机的 `无尽布阵工具v2/src` 布局）。
- 跑测试（无需任何环境，Node 即可）：`node test/test_v2.js`（source/core 同级放一份 src 后按 README 说明）与
  `node test/test_v3.js`（source/app 下）。
- `无尽布阵工具.html` 就是构建产物 `ui/index.html` 的改名副本；`tools/build_app.py` 会自动把它连同新 exe / 安装包一起刷回 v4 根，无需手动改名复制。

## 九、Agent 接 OpenCode Go（伪装 ZCode 客户端）

OpenCode Go 是中转商：同一会话的请求若被路由到不同供应商，会清空提示词缓存。它官方文档里 **ZCode 属"已验证客户端"、Go 能识别 ZCode 原生会话请求头**——所以最稳的接法是**伪装成 ZCode**：发 ZCode 的 `user-agent` + 每段对话稳定的 `x-session-id`（UUID），Go 就把它当 ZCode、保住缓存，连 `x-opencode-session` 都不必发。（本方案据实测 ZCode→网关报文复刻，已弃用早期的 `opencode/1.0.0` 伪装。）

- 设置 ⚙️ → Agent 客户端 → 编辑，勾 **「伪装 ZCode 客户端」**即可。端点含 `opencode` / `z.ai` 的配置会在载入时自动勾上（含老配置里已勾过会话头的，自动迁移）。
- 勾选后：每新建一个 Agent 任务生成一个稳定会话 ID（UUID），随该对话多轮续聊保持不变（新任务另起），每次请求带 `x-session-id` + `x-zcode-*` 身份头 + ZCode `user-agent`。
- **User-Agent 可自定义**（编辑框「User-Agent」）：留空即用 ZCode 默认 UA `ZCode/3.11.2 ai-sdk/provider-utils/4.0.39 runtime/node.js/24`；想换别的客户端标识改这一栏。注意 UA 只在桌面版生效——浏览器 fetch 禁止覆写 User-Agent（web 版仍会带 `x-session-id` 等 `x-*` 头）。
- 建议同时把「思考强度」设为「低」（opencode 端点已自动迁移），推理模型提速明显。
