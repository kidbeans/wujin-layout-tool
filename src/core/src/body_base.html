🧩 无尽布阵小工具（主植物+融合+藤蔓）

📄 阵型文本格式规范与完整说明见同目录 README.md

📖 使用说明 / 导入示例（点击展开）

布阵：点选植物库 → 点格子放置；也可把植物直接拖到格子/卡槽。格子↔格子拖拽互换，列头↔列头拖整列互换，行号↔行号拖整行互换。右键清空格子/卡槽，右键植物名从库中删除，双击格子改主植物名（- 清空）。

叠种：藤蔓（毒藤/南瓜头/豆藤/小守卫菇）叠在主植物上 → 显示 桑葚(毒藤)；融合（原豌/电豌/火豌/冰豌/毒豌）只叠在"大哥"上 → 棋盘显示 原大/电大/火大/冰大/毒大 并带专属特效（电大闪电、火大火焰、冰大下雪、毒大紫烟、原大加粗），导出文本仍为完整 大哥+电豌 格式；毒藤叠桑葚/药师有紫烟缭绕；鸭梨大弟带雷霆水流特效。

导入：点「导入阵型」粘贴任意文本即可自动还原。支持下方 4 种格式；其中 原大=大哥+原豌、电大=大哥+电豌、原碗 自动纠正为原豌、-/空=空格；文本不带卡槽时保留现有卡槽。瓷砖用 [瓷] 后缀标记（如 大哥+原豌[瓷]，兼容 [瓷砖]）。示例（原大桑葚阵）：
