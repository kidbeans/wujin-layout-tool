# v3beta 优化大纲

> 生成方式：创建 v3beta 工程副本后，由主代理自审启动链/UI 层 + 派出探索子代理审计 Agent/桥接层，
> 汇总成下表并**自动实施**了「已落地」项。基座（无尽布阵工具v2/src）保持只读共享，
> v3beta 的差异化全部通过 `build.py` 构建期覆写（tools/patch_v1.py）与 src 覆盖实现。

## 二、已识别、暂不实施（含理由）

| 项 | 说明 | 不做的原因 |
|---|---|---|
| CSS 三层合并（style_base/maa/themes） | 三套深浅调色板与 v3 chrome 变量强耦合 | 重写回归面太大，收益仅 -20KB；等主题体系稳定 |
| 60_agent renderRuns/renderClients 增量渲染 | 现为 innerHTML 全量重建 | runs≤30 无感知卡顿；事件委托改造回归面大 |
| 流式 MD 重渲染 O(n) | 每 120ms 全量渲染尾部 6000 字 | 已有截断，长输出场景罕见 |
| load() 一次性迁移逻辑删除 | 老 args JSON 迁移、移除 ollama | 老用户存档仍可能携带 |
| 05_plant_icons 拆懒加载 | 单文件架构下收益有限 | 构建产物已 1.9MB，需改加载模型 |
| Rust 侧 agent_http SSE 与 web 双实现合并 | 双形态固有两份，注释已对齐协议 | 合并需动 Rust，跨语言回归成本高 |
