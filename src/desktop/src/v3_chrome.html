🤖 Agent 客户端
推荐组合：① zcode / agy / Claude Code 等 CLI——任务包写入工作目录，Agent 能读文件、按 MPZ 工程规范做针对性体检 （zcode 会自动探测 ZCode 桌面端内核 resources/glm/zcode.cjs 并以 node 启动；zcode/agy 用「读 任务包.md」短指令驱动， 不受 Windows 32K 命令行限制）。② DeepSeek API——填 key 即用，流式输出；③ ZCode 目录预设——智谱维护的中国 LLM 双协议端点，一键填充。
确认实际模型：claude 用 -p --output-format json 看 modelUsage 字段（可被 CC Switch 等改路由）； agy 用 agy models 列表 + --model 指定；zcode 桌面端 TUI 内 /model， headless 需 ~/.zcode/cli/config.json 配 model provider；HTTP 客户端=你配置的 model 字段。
