# 布阵体检工作流

## 任务路径

| 路径 | 目标 | 输出 |
|---|---|---|
| `体检` | 当前上下文中的布阵与 pipeline 片段 | P0/P1/P2 问题清单 + 总体结论 |
| `复核` | 已有检查报告 + 布阵上下文 | 对报告逐条复核：确认/降级/推翻，并补充漏报 |

用户未指明路径时按 `体检` 执行。

## 检查面（缺哪块就跳过哪块，并在结论里声明范围）

1. **棋盘合理性**：挂机核心（大哥系/桑葚系）覆盖与补种位；Boss 输出位（叠种/豌豆迫击炮系）是否被挤占；藤蔓叠种合法性（毒藤只叠主植物、融合只叠大哥）；瓷砖格与一次性植物（能量花/蓓蕾）不占产出。
2. **卡槽一致性**：棋盘中出现的植物是否都能在卡槽 1~8（或配队2 的 9~16 别名）找到；金卡检测位是否有回退。
3. **顺序链（O 规则）**：引用 `order-review` 技能逐条核对。
4. **路由参数（R 规则）**：引用 `route-review` 技能逐条核对。
5. **Boss 链（B 规则）**：引用 `boss-review` 技能逐条核对。
6. **pipeline 红线**：引用 `mpz-redlines` 技能对片段逐节点核对。

## 分级标准

- **P0 致命**：违反红线（断链/超时崩溃/deck2 被抢占/喂豆不成环/重置错位），或阵型结构性问题（核心位缺失、Boss 位无输出）。
- **P1 建议**：不阻断但显著影响效率/容错（补种节奏、捡花缺失、时序冗余、参数偏保守）。
- **P2 打磨**：风格与可维护性（节点命名、注释缺失、重复结构可合并）。

## 停止条件

- 每个问题给【依据】（引用节点名/格子/参数原文）+【风险】+【修改建议】（可落地形态）。
- 全部检查面过完，或证据不足的问题已归入「未决」并说明解除方式，即可输出总结论。
