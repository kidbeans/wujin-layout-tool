# Boss 链审查（B1~B6）

## 核对清单

| 规则 | 内容 |
|---|---|
| B1 目标格 | 叠种/喂豆/加速的目标格在棋盘有效范围内；融合目标是大哥所在格 |
| B2 循环收尾 | 链尾循环步必须能回环（自循环或回指已见喂豆节点）；末步循环标记与范式一致 |
| B3 喂豆对象 | 喂豆喂的是已有大-awaiting 状态的输出位；喂豆前目标格已落位 |
| B4 能量花 | 能量花步在其消耗方之前，且注明一次性（不进常规补种） |
| B5 节奏 | 叠电大范式=叠×2轮→(能量花)→加速→循环喂豆；喂豆开大范式=喂豆→加速→喂豆→循环（末步循环）；步序与所选范式一致 |
| B6 血厚教训 | 高血量 Boss 首轮输出不足时先补叠种/喂豆再进循环；禁止只靠单喂豆硬磨 |

## 输出形态

- 修正 ops 用 JSON 数组（与工具 Boss 面板同构）：`[{"op":"stack|feed|accel|flower","cell":"列-路","loop":bool}, …]`
- 注明每步修改原因（引用 B 规则号）；识别 boss 关→神器补给骨架由导出自动补齐，无需手动列。
