# 阵型设计工作流

## 输入确认

用户要求可能包含：世界（复兴/童话/桑葚/海盗/西部/埃及）、双卡组或单卡组、挂机效率优先或 Boss 分数优先、
竞速或稳容错。要求含糊时先声明采用哪个默认假设再设计，不要反问阻塞。

## 设计约束

- 只使用工具植物库存在的植物名（以「阵型 JSON」上下文中的卡槽与植物库为准），不虚构植物。
- 双卡组阵型须给出 配队1/配队2 两个卡槽表；单卡组只给 1~8。
- Boss 输出位（叠电大等融合）每路至少保障一个；挂机核心链不被 Boss 位挤占。
- 藤蔓只叠主植物；融合只叠大哥；瓷砖格独立标记 `[瓷]`。

## 输出形态

1. **可导入文本**：列/路格式（与工具导入格式一致），卡槽行附后——这是第一优先交付物，必须完整可粘贴。
2. **与原阵型差异表**：格子级 diff（列-路 | 原 | 新 | 理由）。
3. **取舍理由**：挂机效率 / Boss 输出 / 容错三视角各一句。
4. 若调整影响顺序链或路由参数，给出需同步修改的最小清单（不展开完整链）。
