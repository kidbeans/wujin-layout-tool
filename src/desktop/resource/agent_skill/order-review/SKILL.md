# 遍历顺序审查（O1~O8）

逐条核对，每条违规给：步编号 + 依据 + 修正后的顺序片段（保留原步编号便于回填）。

| 规则 | 内容 |
|---|---|
| O1 覆盖 | 棋盘上每个需要种植的格子都被顺序覆盖；分阵型下前期/后期步并集 = 总阵型 |
| O2 融合次序 | 融合步（原大/电大等）必须在大哥落位之后；藤蔓叠种步在主植物之后 |
| O3 时序 | 金卡检测（检）步在其目标种植步之后；喂豆/加速在对应输出位落位之后 |
| O4 检测位 | 检测步的失败回退目标存在且合理（回退到补种/等待步，不能悬空） |
| O5 插缝 | 插缝结算（interleave）紧跟其触发种植组之后，不跨越点波 |
| O6 deck2 点波 | deck2 的点波步只能出现在 deck2 关（尾数 3/8 或阶段路由指定关）链内 |
| O7 捡花 | 捡花（sweep）步在产花植物落位后出现，且每轮不超过必要次数 |
| O8 节奏 | 连续种植步之间无多余等待；等待步（delay）只出现在有明确等待对象处 |

## 额外核对

- 同格去重：同一格子重复出现种植步时确认是否叠种意图，否则报 P1。
- 步数规模：单 deck 步数异常（>80）提示可能混入他链。
- 点波四元组：识别/点波/结算/重入的 target 一致性（配合 S9/S17/S18 口径）。
