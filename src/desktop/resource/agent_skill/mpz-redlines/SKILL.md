# MPZ / MaaFramework pipeline 红线

评审任何 pipeline 片段、task 覆盖、agent 参数时，以下为硬约束依据。违反任意一条即为 P0（除非上下文有明确豁免说明）。

## 流程控制

1. `next` 是顺序遍历非并行：候选列表第一个命中即执行，后续项只是备选回退；排序即语义。
2. 识别型候选默认 `timeout: 20000`；长等待（判断进关、等结算、等弹窗）必须显式 `timeout: -1`，否则 20s 超时崩溃。
3. ColorMatch（色值判断）父节点的 `next` 必须 ≥2 项——识别失败无回退会直接超时。
4. `max_hit: 0` 等于永久禁用该节点；要"不限制"就删除该字段。**禁止**用 max_hit 实现"每关一次"（max_hit 跨关累计不重置）。
5. 循环重启节点（`重置到1`）必须直连 `初始化完毕`（跳过入口链），否则被"启动时关卡数"选项错位一关。
6. 节点 `interrupt` / 回环必须有配套退出条件；无限自环无退出 = 挂死。

## 数据与挂载

7. `custom_action_param` 是双层编码：值被序列化成 JSON 字符串字面量，Python agent 侧必须解两层。
8. 全任务只能有一个 input 覆盖同一 custom 节点，多个会互相污染。
9. interface.json 只追加不整写（`resource[]` / `import[]` / `task[]` / `agent` 四处挂载）；自制内容全部放 `resource_self/`，防官方更新覆盖。
10. 卡槽 9~16 是配队2 的别名槽：双卡组共屏 8 槽位，卡槽 9~16 复用卡槽 1~8 的屏幕坐标，site.json 需补别名。
11. 坐标系为 720 短边（MPZ v0.4.2 JSONC）；跨分辨率迁移坐标按 ×2/3 换算并做越界自检（x>1280 / y>720 报错）。

## 双卡组与 agent 计数

12. 配队切换是两步式：切按钮/进选卡界面 → 点卡组；点击后必须 `post_delay` 等弹窗动画；卡组选项**双击**（间隔 500ms）防半载。
13. agent 计数尾数分流默认：尾数 1/2/4/6/7/9 → 配队1 补种；3/8 → 配队2 种植；5/0 → Boss。deck2 关与 Boss 关不得被 deck1 种植链抢占。
14. 喂豆循环必须能回环（自循环或回指已见喂豆节点）；"快速点波循环"识别为 wave；点波四元组（识别/点波/结算/重入）target 必须一致。

## 检查口径（S/T 系）

15. S1 断链 S2 悬空 S3 孤岛 S4 检测回退 S5 禁 max_hit S6 长等待 S8 deck2 隔离 S9/S17 点波四元组 S10 重置到1 S11 入口→初始化 S12 未定义锚点 S13 坐标越界 S14 卡槽 9~16 别名 S15 喂豆循环 S16 回环配套 S18 点波 target 一致 S19 boss 色值 S20 OCR 完整 S21 Swipe 完整 S22 延时；T1~T4 task 红线 T5 参数白名单 T6 select 兜底 T7 interface 挂载。
