# 无尽布阵工具（手机版）

植物大战僵尸2「无尽」布阵工具的手机版：**一个 HTML 文件、零依赖、零后端**，手机浏览器打开即用。
界面以棋盘为主，植物库 / 卡槽 / 工具栏 / 导出区收成底部浮层抽屉；长按格子=清空，双击格子=手输入名字。

- 在线地址：**https://kidbeans.github.io/wujin-layout-tool/**（手机可直接打开并「添加到主屏幕」）
- 仓库：https://github.com/kidbeans/wujin-layout-tool
- 本地文件：`index.html`（2.2MB，直接下载到手机也能离线用）
- 数据存在**浏览器本地**（localStorage），关掉再开还在；换设备请用「📤 导出 → 导出 JSON v2」带走阵型

## 手机上的操作

1. 底部五个键：🪴 植物库 / 🎴 卡槽 / ⚙️ 工具 / 📤 导出 / 🔍 放大（点开是浮层，点浮层外空白处收起）
2. 点植物 → 点格子放置；连点多个格子连续粘同样组合
3. **长按格子 = 清空**；双击格子 = 手输入植物名（输入 `-` 清空）
4. 左栏图标（顺序 / 路由 / Boss / 检查 / 存档 / 导入导出 / 帮助 / 设置）在手机上以底部浮层打开，右上角 ✕ 收起
5. 建议「添加到主屏幕」，像小 App 一样点开即用
6. 手机上没有的：Agent 工作台、一键部署到 MPZ（需要电脑端的桌面版）

## 说明

- 与 MaaPVZ 自制无尽脚本工作流配套：在手机上调阵型 → 导出 JSON v2 / 复制文本 → 电脑端桌面版导入继续出脚本
- 文件内不含任何密钥或个人信息；构建时植物图标、样式、脚本全部内联
- 桌面浏览器打开同样可用（会自动切回桌面布局，多于 840px 宽时手机适配层不介入）

*个人自用工具，按需取用。*
